# 🎮 Rock Paper Scissors – JavaScript Game

A simple browser-based Rock Paper Scissors game built using JavaScript.

The game allows a player to compete against a computer opponent with randomised choices and dynamic score tracking.

## Features

- Player vs computer gameplay
- Random computer selection
- Live score updates
- DOM manipulation with JavaScript
- Simple responsive UI

## Tech Stack

- HTML
- CSS
- JavaScript

## How to Run

Clone the repository and open:

RockPaper.html

in your browser.
